# 設定

## ⏰ スケジュール

引数なしで起動すると、`Worker:Schedules` の要素ごとに cron の時刻でアクションを動かす。

| 項目 | 必須 | 既定 | 内容 |
| --- | --- | --- | --- |
| `Name` | ○ | — | スケジュールの名前(一意) |
| `Cron` | ○ | — | 5 項目(分 時 日 月 曜日)か、先頭に秒を足した 6 項目。実行環境のローカル時刻で動く。曜日は `0`〜`7`(`0` と `7` が日曜) |
| `Action` | ○ | — | 動かすアクション(`hello` / `cleanup`) |
| `Arguments` | | 空 | アクションに渡す引数 |
| `Misfire` | | `Skip` | 取りこぼした回の扱い。`Skip` は 1 回だけ動かして今の時刻から再開、`CatchUp` は取りこぼした回を続けて動かす |
| `MaxCatchUp` | | `0` | `CatchUp` で続けて動かす回数の上限(`0` は上限なし) |

## 🧹 保持ポリシー

`cleanup` はすべてのポリシーを設定の順に動かし、`cleanup <名前>` はそのポリシーだけを動かす。

| 項目 | 必須 | 既定 | 内容 |
| --- | --- | --- | --- |
| `MaxFiles` | ○ | — | 1 回の実行で処理する数(削除 + 失敗)の上限 |
| `MaxSeconds` | ○ | — | 1 回の実行の時間の上限(秒) |
| `Policies` | | 空 | ポリシーの一覧 |

| ポリシーの項目 | 必須 | 既定 | 内容 |
| --- | --- | --- | --- |
| `Name` | ○ | — | ポリシーの名前(一意)。前回の結果のファイル名にも使う |
| `Directory` | ○ | — | 対象のフォルダー。相対パスは実行ファイルのフォルダーが起点 |
| `RetainDays` | | `0` | 更新日時がこの日数より前のファイルを消す(`0`〜`3650`) |
| `Extensions` | | 空 | 消す拡張子(`.log` の形。大文字小文字は区別しない)。空ならすべて |
| `MaxDepth` | | `0` | 下のフォルダーを見る深さ。`0` は直下だけ(`0`〜`32`) |
| `MinSize` / `MaxSize` | | なし | 大きさ(バイト)の下限・上限。範囲に入るファイルだけ消す |

- 消すのはファイルだけで、シンボリックリンクとジャンクションの先へは入らない
- 上限に達したら、そのポリシーで打ち切り、残りのポリシーは動かさない

## 📈 実行結果

- ログ: ポリシーごとの `Cleanup summary` と実行全体の `Action summary`(消した数・残した数・失敗の数・解放した大きさ・所要時間・打ち切り)
- 前回との差: ポリシーごとの `Cleanup compared`。前回の結果は `Worker:History:Directory` の `cleanup.<ポリシー>.json` に置き換えで保存する

## 🚦 終了コード

バッチ(引数を付けた起動)の終了コード。

| コード | 内容 |
| --- | --- |
| `0` | 成功 |
| `1` | 消せなかったファイルがある |
| `-1` | 例外・不明なアクション・不明なポリシー |

## ✅ 設定の検証

次の誤りで起動を止める。

- 知らない項目の名前・変換できない値
- 必須の欠け・範囲外・名前の重複・`MinSize` が `MaxSize` より大きい
- cron の書式
